# Modelling3DFive

Unreal Engine 5.7 project (C++) from the geometric modelling course at Gamagora, on subdivision.

`USmoothSubdivisionComponent` applies Catmull-Clark, bilinear or Loop subdivision to a static mesh at runtime and can restore the original mesh. `AlgorithmDeChaikin` holds Chaikin corner-cutting for 2D and 3D point curves, with visualiser actors.
